
# Lab 2: Relational Schema & Data Definition Language (DDL)

## 🎯 Objective
Convert the Lab 1 ER diagram into a relational database schema using MySQL DDL statements.

## 🧠 Concepts Covered
- Relational Mapping
- MySQL `CREATE TABLE`
- Primary & Foreign Keys
- Constraints (`NOT NULL`, `UNIQUE`)
- Referential Integrity (`ON DELETE CASCADE`, `SET NULL`)

## 🏗️ Implementation Overview
Write SQL scripts to define tables corresponding to the E-commerce ER model. Enforce strict data types and schema rules.

## 📝 Procedure
1. Map entities to tables and attributes to columns.
2. Write `CREATE TABLE` commands defining PKs and FKs.
3. Apply constraints such as `UNIQUE` and `NOT NULL`.
4. Insert sample data.
5. Write statements violating constraints (e.g., inserting a duplicate PK) to demonstrate database-level referential integrity enforcement.

## 🎓 Learning Outcomes
Practical understanding of how to physically implement a conceptual data model into an RDBMS.
