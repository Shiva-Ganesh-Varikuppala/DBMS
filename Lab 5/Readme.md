
# Lab 5: Database Views and Recursive CTEs

## 🎯 Objective
Create updatable views and use Common Table Expressions (CTEs) to handle hierarchical data.

## 🧠 Concepts Covered
- SQL Views (Simple & Complex)
- View Updatability
- Common Table Expressions (CTEs)
- Recursive CTEs for Hierarchies

## 🏗️ Implementation Overview
Abstract complex queries into views for department summaries and implement a recursive query to traverse reporting hierarchies (e.g., Manager-Employee chains).

## 📝 Procedure
1. Create a view summarizing department salaries.
2. Test `INSERT`/`UPDATE` operations on the view to verify updatability rules.
3. Write a standard CTE for temporary result sets.
4. Write a Recursive CTE to display an organizational chart or reporting chain.

## 🎓 Learning Outcomes
Ability to secure/abstract data access using views and navigate tree-structured data natively in SQL.
