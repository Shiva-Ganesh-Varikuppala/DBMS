
# Lab 3: Basic SQL, Data Manipulation, and Aggregation

## 🎯 Objective
Create an Employee-Department-Project schema and execute data retrieval queries using basic and aggregate SQL functions.

## 🧠 Concepts Covered
- Data Manipulation Language (DML)
- `SELECT`, `WHERE`, `ORDER BY`
- Aggregate Functions (`SUM`, `AVG`, `COUNT`)
- Grouping (`GROUP BY`, `HAVING`)
- Conditional Logic (`CASE` expressions)

## 🏗️ Implementation Overview
Design tables for Employees, Departments, and Projects. Populate with at least 30 employees distributed across 5 departments and 8 projects.

## 📝 Procedure
1. Create tables and insert the required 30+ records.
2. Write queries selecting specific columns (projection) and filtering rows (selection).
3. Implement aggregate functions to calculate departmental statistics.
4. Use `GROUP BY` and `HAVING` to filter aggregated results.
5. Write a query utilizing a `CASE` expression to categorize data dynamically.

## 🎓 Learning Outcomes
Proficiency in extracting and summarizing meaningful information from normalized database tables.
