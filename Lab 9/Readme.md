# Lab 9: Indexing and Performance Analysis

## 🎯 Objective
Create a large dataset (5,000+ records) and benchmark query execution times before and after creating single-column and composite B-Tree indexes.

## 🧠 Concepts Covered
- Primary vs Secondary Indexes
- Composite / Multi-column Indexes
- B-Tree Index Internals
- Execution Plan Analysis (`EXPLAIN ANALYZE`)
- Index Cardinality and Selectivity

## 🏗️ Implementation Overview
Populate a Railway Booking dataset and optimize frequently queried filter combinations.
