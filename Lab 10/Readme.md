# Lab 10: Query Optimization and Rewriting

## 🎯 Objective
Analyze bottleneck queries on a 10,000+ record dataset and optimize them by rewriting queries, eliminating correlated subqueries, and leveraging index hints.

## 🧠 Concepts Covered
- Query Profiling (`SHOW PROFILE`, `EXPLAIN`)
- Subquery to JOIN transformations
- Avoiding Table Scans (`ALL` -> `ref`/`range`)
- Index Hints (`USE INDEX`, `FORCE INDEX`)
- Pagination Optimization

## 🏗️ Implementation Overview
Identify five representative slow queries and document execution cost improvements through systematic query refactoring.
