# Lab 7: Database Normalization (UNF to BCNF)

## 🎯 Objective
Normalize a Sales table step-by-step from Unnormalized Form (UNF) to First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF), and Boyce-Codd Normal Form (BCNF), verifying lossless join decomposition and functional dependency preservation.

## 🧠 Concepts Covered
- Functional Dependencies
- 1NF, 2NF, 3NF, and BCNF
- Lossless Join Decomposition
- Dependency Preservation

## 🏗️ Implementation Overview
Analyze redundant repeating groups in an unnormalized relational schema, isolate partial and transitive dependencies, and decompose the tables systematically.
