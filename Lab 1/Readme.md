
# Lab 1: Entity-Relationship (ER) Modeling

## 🎯 Objective
Design a comprehensive ER diagram for an Indian e-commerce platform.

## 🧠 Concepts Covered
- Entity Types & Attributes (Composite, Multi-valued)
- Weak Entities
- Primary Keys
- Specialization & Generalization
- Participation Constraints

## 🏗️ Implementation Overview
Identify core entities such as Customer, Product, Order, OrderItem, Seller, Category, Payment, Delivery, and Address. Establish relationships defining cardinality and participation.

## 📝 Procedure
1. Define all strong and weak entities.
2. Assign simple, composite, and derived attributes.
3. Identify relationships (e.g., Customer places Order, Product belongs to Category).
4. Specify constraints (total/partial participation) and map out the specialization for 'Product'.

## 🎓 Learning Outcomes
Ability to conceptualize real-world business requirements into a structured conceptual data model using ER diagrams.
